## Wording

- Call an AppMap recording a "trace", not a "recording". This applies to
  everything a viewer reads or hears: titles, captions, support lines, alt
  text, the showcase's title and description, and the text inside graphics.
  Write "one AppMap trace of a test", not "one AppMap recording of a test".
- The verb is fine: a test is still "recorded", and a helper still "records"
  a test.
- Call what a diagram skill produces a "diagram", not a "page". The reader
  thinks of it as a diagram; that it is an HTML file is a detail.
- Show how to use a feature (what to ask Claude, what comes back), not how
  it works inside (scripts, flags, file formats).
- A graphic's first part is on screen from the scene's first frame, with no
  fade-in. Only the later parts animate in. A scene never opens on an empty
  panel.
- Screenshots of real product output keep whatever words the product prints.
